# Festival DevOps Music Fest

Proyecto desarrollado para la actividad de aprendizaje #6 del programa DevOps y Contenedores (Docker).

## Descripción

Festival DevOps Music Fest es una aplicación compuesta por un frontend y un backend en Flask, administrados mediante Docker y Docker Compose.

## Estructura del proyecto

```
festival-devops/
├── frontend/
├── backend/
├── docker-compose.yml
└── README.md
```

## Tecnologías utilizadas

- HTML5
- CSS3
- Python
- Flask
- Docker
- Docker Compose
- Git
- GitHub

## Frontend

El frontend contiene la página principal del festival y está compuesto por:

- index.html
- style.css

## Backend

El backend está desarrollado en Flask y contiene:

- app.py
- requirements.txt
- Dockerfile

## Docker

Docker permite crear contenedores para ejecutar la aplicación de forma aislada.

## Docker Compose

Docker Compose permite administrar y ejecutar los servicios del proyecto desde un solo archivo llamado:

- docker-compose.yml

## Control de versiones

Para el control de versiones se utilizó Git, realizando commits y trabajando con ramas para cada funcionalidad.

### Ramas utilizadas

- main
- feature-landing
- feature-backend

## Repositorio remoto

El proyecto se encuentra almacenado en GitHub para facilitar su administración y colaboración.
